# Beeskilled-sales-profitability-analysis-dashboard

## 📊 Business Questions

### Dashboard 1 – Sales Overview
- What is the overall sales performance of the business?
- Which months have the highest and lowest sales?
- Which countries generate the most sales?
- Which products contribute the most to total sales?
- Which customer segments generate the highest sales?

### Dashboard 2 – Profitability Analysis
- Which products generate the highest profit?
- Which products have the lowest or negative profit?
- Which countries are the most profitable?
- Which customer segments contribute the most profit?
- How does profit change over time?

### Dashboard 3 – Discount & Performance Analysis
- How do discounts affect sales and profitability?
- Which discount levels generate the highest profit?
- Which products receive the highest discounts?
- Does a higher discount result in higher sales?
- What discount strategy can help improve overall profitability?
